小贴士

  • 默认方案：屏幕用单元格后方的背景水印，打印用页眉图片水印，两者都不是浮动对象，鼠标点击和输入不受影响。
  • WPS 护眼模式会在单元格背景之上铺一层护眼色，会把工作表背景水印盖住 —— 这是 WPS 的图层顺序决定的；需要护眼模式下也可见，只能用浮动水印，但那样会吃掉鼠标点击。
  • 用 Excel 打开时，如果看不到背景水印，先确认当前是不是「分页预览 / 页面布局」视图：工作表背景图只在「普通视图」显示。
  • 需要纸质文件也带水印时，请开启「打印水印」。
  • 覆盖水印已设置为不可选中；若要删除，可在「开始 → 查找和选择 → 选择窗格」中删除名为 Watermark 的对象。
  • 若所选字体在当前系统缺少部分简体字形（例如苹方、宋体在部分环境不可用），系统会自动换成可用的中文字体，并在预览下方提示。
  • 生成过程只读取并重写水印相关的 XML 片段，单元格内容、公式、图表、宏均保持不变。
